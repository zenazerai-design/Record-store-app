Typography

Three font families: General Sans for display, Manrope for body, JetBrains Mono for labels and meta. Scale is defined as CSS custom properties on :root.

Font families

Token Family Weights used Role
--font-display General Sans 600, 700, 800 Hero headlines, section titles, large case study titles, display flourishes
--font-body Manrope 400, 500, 600 Body copy, nav links, card summaries, subtitles, UI labels
--font-mono JetBrains Mono 400, 500 Kickers, eyebrows, pills, footer links, dates, track numbers
--serif / --sans / --mono Legacy aliases — Map to display, body, and mono respectively

Layout & motion

Shared spacing, radius, and easing tokens. Case study pages add local --csd-* section padding variables.

Token Value Usage
--pad clamp(20px, 4vw, 56px) Horizontal page padding, nav inset, section gutters
--maxw 1280px Content max width for hero, sections, crate, footer
--radius 14px Record cards, case study covers, general surfaces
--radius-cta 3px Buttons (.nav__cta), image corners via --radius-image
--ease cubic-bezier(.2, .7, .15, 1) Default transitions: hovers, reveals, nav
--ease-premium cubic-bezier(0.16, 1, 0.3, 1) Hero and premium motion curves
--reveal-duration 0.75s Scroll reveal animations (.reveal)
--csd-section-pad clamp(80px, 7.5vw, 112px) Case study section vertical rhythm
--csd-section-pad-tight clamp(40px, 3.8vw, 56px) Tighter gaps between related CSD blocks
--csd-section-pad-loose clamp(104px, 9.5vw, 144px) Statement strips, viewport-height sections

Global effects

Class Description
.grain Fixed SVG film grain overlay (opacity ~0.07, mix-blend-mode overlay). Reduced on home hero.
.reveal Scroll-triggered fade/slide. Variants: --lift, --slide-right, --scale, --soft, --stagger.
.marquee Infinite horizontal scroll banner. Star character uses --amber.
